# 1. Purpose

This form records the formal customer and delivery-team decision at the end of the Mine Manager AI Version 1.0 pilot.

The sign-off confirms:

- The agreed pilot scope
- The acceptance-test result
- Achievement of pilot success criteria
- Outstanding defects and observations
- Approved workarounds
- Remaining actions
- Known Version 1.0 limitations
- Customer feedback
- The commercial next-step decision

This form should be completed only after the acceptance-test report, defect review, backup and restore validation, security review, and pilot success-criteria review have been completed.

# 15. Known Limitations

Record accepted Version 1.0 limitations:

```text

```

Typical Version 1.0 limitations may include:

- Centralized cloud log aggregation is not included
- File logging may not be enabled in every pilot environment
- Real-time dispatch integration is not included
- Real-time SCADA integration is not included
- Direct control of mining equipment is not included
- Direct control of processing-plant systems is not included
- Autonomous equipment control is not included
- Safety-critical control is not included
- Mobile application is not included
- Advanced enterprise integrations are deferred
- Executive Decision Center is deferred to Version 2.0
- AI Mine Operations Copilot is deferred to Version 2.0
- Customer-specific integrations require separate scope
- Forecast accuracy depends on data quality and history
- AI outputs remain decision-support information
- Authorized customer personnel retain responsibility for all operational decisions
