# 1. Purpose

This document defines the formal acceptance test cases for Mine Manager AI Version 1.0.

# 2. Status Values

| Status | Meaning |
|---|---|
| Not Run | Test has not been executed |
| Passed | Expected result achieved |
| Failed | Expected result not achieved |
| Blocked | Test cannot proceed |
| Passed with Observation | Test passed with a non-blocking observation |

# 3. Test Execution Rules

1. Record the actual result.
2. Select a status.
3. Reference evidence.
4. Record tester and date.
5. Create a defect when the expected result is not achieved.
6. Retest after correction.
